# Development Guide  
Database: PostgreSQL via Docker Compose  
ORM: Prisma  
API: NestJS  
Frontend: Next.js 
  
## Lead Submission (Phase 1C)  
To test lead submission locally, ensure PostgreSQL is running and the NestJS API is up. Visit /contact or /request-quote in the Next.js frontend to submit an inquiry. Deduplication and admin retrieval are deferred to Phase 1D (Admin Dashboard) and authentication.
